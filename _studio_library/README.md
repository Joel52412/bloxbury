# Studio Asset Library

Approved assets only, signed off by Joel on 21 Nov 2026.

- `engine/`: the Blender Python that builds every asset. `studio.py` is the registry: only what's listed there gets used in episodes.
- `approval_sheets/`: the images Joel approved.
- `manifest.json`: the same list in machine-readable form.

New assets go through a test sheet and Joel's sign-off before they're added here.
