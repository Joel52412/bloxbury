# RunPod rendering (read only when a pod is needed)
Rules from CLAUDE.md apply: Joel OKs every pod after seeing $/hr, time and total cost per option.

- **Fastest first:** run `get-capacity` (gpuCount 3/2/1, CUDA 13.2) and offer the fastest setup actually in stock; multi-GPU often isn't. A persistent mount narrows hosts: drop it if nothing places.
- **Cards:** default 3× Community RTX 4090 ($0.34/hr each); Secure 4090 $0.89/hr; A40 Secure $0.59/hr. Always `allowedCudaVersions: ["13.2"]` (inside `gpu`): 13.0 Community 4090s broke 3 times. Check torch CUDA in the first minute; delete if broken. ~1.5 s/frame per 4090, ~3 s per A40.
- **Create body:** image `runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404` (pod_setup installs Blender, ~2 min; `ghcr.io/joel52412/bloxbury-render:5.3` only once the GHCR package is public), disk 30, `mounts: {persistent: {size: 20, path: /workspace}}` (without it the 60-min auto-stop wipes an undownloaded render), port 8888/http, startJupyter, `env: {"GITHUB_RO": "{{ RUNPOD_SECRET_GITHUB_RO }}"}` at create time (changing env later wipes the pod). Spot pods: GraphQL only, not from here.
- **On the pod:** `T=$(tr '\0' '\n' < /proc/1/environ | sed -n 's/^GITHUB_RO=//p')`; `git clone --depth 1 https://x-access-token:$T@github.com/Joel52412/bloxbury.git /workspace/bloxbury`; `nohup sh /workspace/bloxbury/_pipeline/pod_setup.sh > setup.log &` (<1 min; lays out every story's scripts + env/captions/audio flat). Token is read-only: pods never push. `exec-pod` calls max 25 s: use nohup.
- **Render:** write `/workspace/render_job.json` (`name, group, total, frame_start, frame_end, cost_per_hr, pod_started, output, audio, captions, black, download_to=stories/<story>/exports/...`), then `sh /workspace/bloxbury/_pipeline/pod_render.sh <id>.py <NF> /workspace/frames` (shared frame queue across GPUs + progress + balancer + auto-finish). Asset stills: `pod_stills.sh <id>_assets.py` → `contact.jpg` + `stills.zip`. Preview: `RX=540 RY=960 SAMPLES=6`. Final: 1080×1920, 32 samples, OptiX, `QUALITY=fast`.
- **Tell Joel when it starts (anything >5 min):** pod ID, Jupyter token, frames link `https://<pod>-8888.proxy.runpod.net/tree/workspace/frames?token=<token>`, cards + $/hr, frames, ETA, cost, backup download link `.../files/workspace/<file>?token=<token>`. Render Monitor (`_tools/Render Monitor.bat`) shows it live.
- **Auto-finish:** `pod_finish.sh` checks frames, assembles (`make_part.sh`); the Render Monitor downloads and writes `received.json`; the pod deletes itself (confirm `runpodctl` syntax on the next pod). No download in 60 min → pod stops. Failure → stage `needs_claude`.
- **Download:** when the stage is `ready`, give Joel the backup link; he downloads it, then delete the pod straight away (Claude can't reach the pod proxy).
- **Pod → Claude images:** small contact-sheet JPG as base64 via exec-pod (≤1 MiB stdout).
