# RunPod rendering (read only when a pod is needed)
Rules from CLAUDE.md apply: Joel OKs every pod after seeing $/hr, time and total cost per option.

- **Fastest first:** run `get-capacity` (gpuCount 3/2/1, CUDA 13.2) and offer the fastest setup actually in stock; multi-GPU often isn't. A persistent mount narrows hosts: drop it if nothing places.
- **Cards:** default 3× Community RTX 4090 ($0.34/hr each); Secure 4090 $0.89/hr; A40 Secure $0.59/hr. Always `allowedCudaVersions: ["13.2"]` (inside `gpu`): 13.0 Community 4090s broke 3 times. Check torch CUDA in the first minute; delete if broken. ~1.5 s/frame per 4090, ~3 s per A40.
- **Create body:** image `runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404` (pod_setup installs Blender, ~2 min; `ghcr.io/joel52412/bloxbury-render:5.3` only once the GHCR package is public), disk 30, `mounts: {persistent: {size: 20, path: /workspace}}` (without it the 60-min auto-stop wipes an undownloaded render), port 8888/http, startJupyter, `env: {"GITHUB_RO": "{{ RUNPOD_SECRET_GITHUB_RO }}"}` at create time (changing env later wipes the pod). Spot pods: GraphQL only, not from here.
- **On the pod:** `T=$(tr '\0' '\n' < /proc/1/environ | sed -n 's/^GITHUB_RO=//p')`; `git clone --depth 1 https://x-access-token:$T@github.com/Joel52412/bloxbury.git /workspace/bloxbury`; `nohup sh /workspace/bloxbury/_pipeline/pod_setup.sh > setup.log &` (<1 min; lays out every story's scripts + env/captions/audio flat). Token is read-only: pods never push. `exec-pod` calls max 25 s: use nohup.
- **Render:** write `/workspace/render_job.json` (`name, group, total, frame_start, frame_end, cost_per_hr, pod_started, output, audio, captions, black, tiktok_audio, shots (optional), download_to=stories/<story>/exports/...`), then `sh /workspace/bloxbury/_pipeline/pod_render.sh <id>.py <NF> /workspace/frames` (shared frame queue across GPUs + progress + balancer (helpers inherit RX/RY/SAMPLES) + watchdog + auto-finish). Asset stills: `pod_stills.sh <id>_assets.py` → `contact.jpg` + `stills.zip`. (Motion preview is free here now: `preview_local.py`.) Final: 1080×1920, 32 samples, OptiX, `QUALITY=fast`.
- **Tell Joel when it starts (anything >5 min):** pod ID, Jupyter token, frames link `https://<pod>-8888.proxy.runpod.net/tree/workspace/frames?token=<token>`, cards + $/hr, frames, ETA, cost, backup download link `.../files/workspace/<file>?token=<token>`. Also send a one-click launcher: `python3 _tools/make_monitor_bat.py "<Name>" /mnt/project-files/<story>/ <pod>:<token> ...` → `Monitor <Name>.bat` (opens the Render Monitor on the laptop with those pods, no typing IDs).
- **Watchdog (`pod_watchdog.sh`, also in `pod_range.sh`):** 0-byte placeholders older than 5 min are deleted (re-rendered); no new frame for 10 min → Blender killed, stage `stalled`, pod STOPPED (frames kept).
- **Export (`encode.sh`, every final mp4):** x264 slow, CRF 15, aq-mode=3, luma grain 2 (~135 MB per 80 s). `GRAIN=0` when re-encoding an already-grained file.
- **Auto-finish:** `pod_finish.sh` checks frames, assembles (`make_part.sh`), writes `<output>_master.mp4` (video-only CRF 10, the render cache), runs `motion_audit.py` (→ status + `/workspace/motion_audit.txt`) and `make_tiktok.sh` (if `tiktok_audio`); the Render Monitor downloads and writes `received.json`; the pod deletes itself (confirm `runpodctl` syntax on the next pod). No download in 60 min → pod stops. Failure → stage `needs_claude`, pod stops after 60 min.
- **Download:** when the stage is `ready`, give Joel the backup link; he downloads it, then delete the pod straight away (Claude can't reach the pod proxy).
- **Black-frame guard (`scene_kit.render`):** Cycles persistent data + motion blur renders an object black/unlit on the frame it starts or stops moving. `motion_flips()` finds those frames (in-view objects + camera, ~35 s pre-pass, cached in OUT) and renders just them without persistent data (Part 3: 36/2023 frames, ~2% time). Frames are claimed with atomic placeholders.
- **Dark shots (`scene_kit.dark_shots`):** a tiny pre-render per shot (~30 s per part) measures brightness; shots darker than 0.13 (not intended black) get 64 samples + noise threshold 0.01, capped at 8% of frames (Part 3: 3 shots, 156 frames, ~+7% render time; +1.8 dB, 22% less flicker on them). `NODARK=1` turns it off; `DARK_LUMA`, `DARK_BUDGET`, `DARK_SAMPLES` tune it. Denoiser stays OIDN HIGH + ACCURATE prefilter: BALANCED/FAST saved only 2-4% and lost 0.6-1.1 dB.
- **Re-render only what changed (any story, Joel 23 Nov):** after a tweak, from the scripts folder: `RX=1080 RY=1920 SAMPLES=32 ENGINE=GPU python3 <repo>/_tools/render_cache.py plan <id>.py` (~1-2 min, free) keys every frame on its render inputs (settings, per-frame samples, camera, every object in or near the view: mesh, materials, images, matrix, animated values, both ends of the motion-blur shutter), compares with the cache, prints changed frames per shot, `RANGES=` and cost. Pod: `sh pod_patch.sh <id>.py "<RANGES>"` → `patch_<id>.mp4` + `.json` (Joel downloads). Then `render_cache.py splice <id> --new patch_<id>.mp4 --out <export.mp4> --audio .. --captions ..` (laptop or here) → new master + export; identical frames a tweak shifted in time are reused. After a FULL render: `plan` with the same settings BEFORE the pod, then `render_cache.py accept <id> --master <output>_master.mp4`. Cache: `stories/<story>/render_cache/` (`<id>.json` keys in git, `<id>_master.mp4` laptop only). Settings change = full render. Local `RANGES=a-b,c` works too. Tested 23 Nov on Part 3: 2 edits → 366/2023 frames; reused frames match a fresh render to 1/255; master re-encode ~51 dB per splice.
- **API from here:** key in a private scratchpad file only (never env dumps, logs or git; it does not survive the thread, so a new render thread needs Joel to paste it or add it as an environment secret). REST `https://api.runpod.io/v2` with `Authorization: Bearer <key>` (`rest.runpod.io` 502s): `GET/POST /pods`, `POST /pods/<id>/action {"action":"stop"}`, `DELETE /pods/<id>`, `POST /pods/<id>/exec {"command":["sh","-c","..."],"timeoutSeconds":25}` (stdout ≤1 MiB). Stock via GraphQL `https://api.runpod.io/graphql`. Give each Secure pod a random `JUPYTER_PASSWORD` env at create (that is its token).
- **Split one part over N single-GPU pods (faster when multi-GPU is out of stock):** each pod `sh pod_range.sh <id>.py FS FE <tag>` → `/workspace/seg_<tag>.mp4` + `render_output.json` stage `ready`; one pod fetches the others' segments over their Jupyter proxy and runs `join_segments.sh` (+ `motion_audit.py`, `make_tiktok.sh`; upload `<id>_tiktok.flac` to it first if the story isn't on main). Height Mog (1679 frames) on 4× Secure 4090: ~35 min.
- **Pod → Claude images:** small contact-sheet JPG as base64 via exec-pod (≤1 MiB stdout).
